# ADR 0020：单文件便携与当前用户安装器

- 日期：2026-10-30
- 状态：接受（本机验收；干净 Windows 待验收）

## 背景

历史 installed ZIP 只是数据布局，没有安装向导；便携目录包含运行时及许多 DLL。不通过重命名 ZIP 宣称完成安装器，不为减少文件删除用户配置或第三方许可。

## 决策

采用 .NET 自包含单文件发布，包含原生库自解包及压缩，嵌入依赖和运行时许可。编译元数据指定单文件默认便携模式，数据在 EXE 旁；installed 标记覆盖默认模式，显式启动参数优先。

用 Inno Setup 生成中文/英文、当前用户安装向导；固定 AppId、可选目录/桌面快捷方式、开始菜单及卸载入口。程序默认在 LocalAppData/Programs，数据保持 LocalAppData/PortHarbor。升级替换登记文件，卸载保留用户数据和未知文件。

最终产物放到 `artifacts/releases`，验收与缓存单列；通过验收后原子发布，不清理历史 artifacts。相同源码通过独立随机 AppId 编译测试安装器，避免覆盖真实安装。工具固定版本并校验官方签名，以便携方式缓存。

## 后果

可直接选择便携 EXE 或 Setup EXE，均无需另装 .NET；包体增大，运行后允许生成配置和临时缓存。运行时补丁需重新发布应用。签名、自动更新及机器范围安装另行安排；干净 Windows 交付验收由实际环境完成。模式、构建和证据见[发行说明](../DISTRIBUTION.md)。
