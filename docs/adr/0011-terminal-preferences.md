# ADR 0011：终端全局默认偏好与临时标签调整

- 日期：2026-10-28
- 状态：已采纳

## 背景

终端右键菜单的字体、配色和复制粘贴选项此前仅作用于当前控件，重启后丢失。P01 需要可预览、可取消的持久化设置，同时保持旧会话、密码库和导入导出兼容。

## 决策

- Application 定义不可变 `TerminalPreferences`、校验、仓储端口与服务；Infrastructure 使用已有应用数据路径读写独立的 `terminal-preferences.json`。首版 schema 为 1，`Terminal` 中缺字段使用默认值，未知 schema 拒绝覆盖。
- 不增加会话 DTO 字段或逐会话模板。保存全局默认只影响新标签及重启后的创建；右键菜单调整仍为当前标签临时状态。设置窗口以草稿驱动预览，恢复默认需保存，取消不写文件。
- 首次读取缺文件不落盘。保存采用同目录临时写入、刷盘、原子替换及单份 `.bak`；写入成功后才发布内存状态。读取异常安全回退并提示，损坏、无效和未来版本文件保留，用户先移走保管后可重新保存。
- 字体名缺失时保留原设置、渲染回退为可用等宽字体；字体枚举对象显式释放。WinForms 可能保留与替换字体相等的原实例，控件仍使用的字体不得释放。
- 终端模型持有可配置默认颜色，ANSI 重置恢复该默认；此设置不承担应用主题、终端兼容性扩展或发行打包职责。

## 后果与验证

额外产生一个独立偏好文件及替换后的备份，换取会话/凭据格式稳定和单独恢复能力。没有未来 schema 自动升级或损坏文件恢复按钮；操作指引见[终端约定](../TERMINAL-SESSIONS.md#终端默认偏好)。

存储回归覆盖安装/便携模式、重启读取、缺字段、坏配置、备份及替换失败；UI 检查覆盖预览、取消、恢复默认、字体回退、相同字体重复应用、新旧标签作用范围和失败后不发布草稿。跨 DPI、高对比度及实际字体组合仍需人工体验验收。
