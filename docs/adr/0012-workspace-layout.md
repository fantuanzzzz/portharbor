# ADR 0012：工作台布局记忆与安全恢复

- 日期：2026-10-28
- 状态：已采纳

## 背景

P02 需要减少菜单查找并记住窗口及侧栏布局。旧主窗口每次使用固定大小与侧栏宽度，开始页协议按钮也使用固定尺寸区域。位置恢复须处理显示器断开、不同 DPI、最小化及损坏配置，同时保持现有会话与终端偏好独立。

## 决策

- 菜单下增加原生 ToolStrip 常用操作栏；沿用原有编辑、连接和关闭路径，不增加凭据副本或连接生命周期分支。开始页按可用宽度换行；侧栏可显隐，搜索入口会先展开再聚焦。键盘约定见[布局说明](../WORKSPACE-LAYOUT.md)。
- Application 定义 `WorkspaceLayout`、仓储端口、保存服务和不依赖 WinForms 的屏幕工作区约束规则。Windows UI 枚举实际工作区，计算当前 DPI 及最小尺寸并应用结果。大小记录保存时 DPI，位置采用桌面坐标；恢复选择与原窗口交集最大的工作区并限制完整窗口范围，未指定位置时居中主屏。
- Infrastructure 沿用已有安装/便携配置目录，独立存储 `workspace-layout.json`，schema 为 1。无需改变会话 JSON/INI 或 P01 偏好格式，文件不包含服务器、路径或凭据。
- 只记录正常位置和大小，最大化单独记录；最小化不覆盖恢复状态。侧栏宽度采用 96 DPI 逻辑单位，窄窗口限制实际宽度但保留偏好值。移动/调整后延迟 750ms 合并保存，确认退出清理结束后再保存一次；恢复默认布局立即应用并尝试保存。
- 保存先刷盘临时文件，再原子替换并保留上一份 `.bak`，成功后更新已保存状态。坏配置/无效值/未来 schema 保留并提示，拒绝自动覆盖；保存失败显示状态栏消息，不阻止连接和退出。发布启动冒烟禁用布局读写，避免污染分发目录。

## 验证和边界

规则检查覆盖移除屏幕、负坐标、小屏、超大窗口和 96/120/144/192 DPI 换算；存储覆盖安装/便携、重启、缺字段、备份及失败保全；桌面检查覆盖键盘、操作栏、窄窗口、自动保存、正常/最大化/最小化、侧栏和恢复默认。

本机截图及实际窗口使用当前系统缩放。规则测试不替代真实多屏拔插、混合 DPI 移屏或所有缩放/高对比度验收；这些仍需人工体验验证。主题、图标规范和应用整体美化按 P03 推进。
