# ADR 0022：会话树根节点与新建默认值

- 状态：接受
- 日期：2026-10-30

## 背景

根分类和子分类的两个入口让用户难以判断创建位置；新会话有固定占位名称，未命名时无法自然使用主机标识；SSH/SFTP 空用户名直到认证构造才失败。

## 决策

1. 树使用固定的 `User sessions` 显示根节点。统一「新建分类」根据当前选择确定父级：根/空白为顶层、分类为其子级、会话为所属分类的子级。显示根不写入配置、不增加真实分组路径或会话记录；保留既有默认分类和分类文件格式。
2. 新建入口以空名称草稿开始。Application 的 `SessionDraftDefaults` 在提交草稿时，为空名称取主机/IP；串口取 COM 名称，Shell 取程序文件名。已有和手动名称保持不变，不增加“自动名称”持久化标志，不按编辑器输入过程改写原对象。
3. Domain 的校验通过 `requireAuthentication` 明确区分兼容性读取与交互使用。默认保持旧配置结构校验；编辑器的全部提交及主窗口连接显式要求 SSH/SFTP 用户名。底层 SSH 配置构造同样拒绝空用户名，且先于私钥读取/网络访问。
4. 不将新要求追溯为旧配置损坏。旧 SSH/SFTP 空用户名记录仍能载入/导入；真正连接前提示用户补填，避免阻止整个配置文件读取或丢失旧凭据关联。

## 影响与验证

没有新增配置文件、schema 或依赖包；收藏/最近仍按会话 ID 解析，新根节点不改变其数据。新建、复制、首页协议按钮与快捷键沿用同一编辑器。

纯逻辑覆盖五种网络协议命名、显式名称、Shell/串口默认和身份校验兼容；UI 覆盖统一分类、根节点、三种提交、错误焦点及旧配置重启读取。测试报告与截图见开发日志本日记录；实际远程服务器、混合 DPI 与原生输入法体验仍单列实机验收。
