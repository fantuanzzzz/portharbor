# ADR 0014：收藏与最近连接只关联会话身份

- 日期：2026-10-28
- 状态：已采纳

## 背景

P04 需要更快定位日常会话，并在重启后保留收藏和最近尝试。复制整份会话/密码到历史记录会制造陈旧端点和额外秘密副本；将活动记录混入会话导出也会改变既有契约。

## 决策

- Application 定义活动状态、仓储端口、集合变更和视图规则；Infrastructure 独立保存 schema 1 `session-activity.json`。记录仅为收藏 ID、最近尝试 ID 与 UTC 时间，沿用安装/便携路径。无数据不主动建立文件；不改变会话 JSON/INI、密码库或导出格式。
- 最近最多保留 20 个不同已保存 ID，重复尝试移到前面。记录进入连接流程的尝试，不声称远程连接成功；取消输入、能力不可用、校验失败及无持久 ID 的临时会话不记录。
- 所有视图都使用当前配置解析 ID。选中连接时再次按 ID 取得当前会话，沿用主密码、临时输入、主机信任和能力检查，不创建新的连接/凭据分支。
- 收藏与最近的保存先写盘再发布内存值；失败保留旧集合并提示。原子替换及 `.bak` 沿用现有偏好策略；坏文件保全，拒绝静默覆盖。
- 删除先完成会话/凭据事务，再清理独立活动文件；不能宣称跨文件原子性。清理失败提示，视图过滤失效 ID，后续刷新/重启重试；坏文件继续保全。
- 全部/收藏使用原分类树，最近平铺以保持全局尝试顺序，文字/提示保留分类路径。重命名保持原身份和密码，复制创建新身份并不复制活动或秘密。相关操作与备份清理边界见[会话库说明](../SESSION-LIBRARY.md)。

## 代价与验证

增加一个小型独立本地文件，换取不修改会话格式、不在每次连接时重写密码库。现有单进程配置约束保持不变；不提供跨设备同步或完整活动审计。通过 Application 规则、真实文件故障和 WinForms 注入连接检查验证新路径，真实服务器登录另列验收。
