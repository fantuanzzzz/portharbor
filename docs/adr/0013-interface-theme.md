# ADR 0013：共享界面样式与终端配色隔离

- 日期：2026-10-28
- 状态：已采纳

## 背景

P03 需要统一当前 WinForms 界面中的字体、按钮、状态和浅色/深色外观，同时保留 P01 的用户终端配置、原生输入控件和键盘操作。

## 决策

- 在 UI 项目集中定义 `UiPalette`、`UiTheme` 和 `UiButton`。颜色使用正文、表面、主操作、选择、成功、警告和错误等语义，样本见[视觉规范](../VISUAL-DESIGN.md)。不向 Domain 或协议层引入绘制依赖。
- Application 的 `WorkspaceLayout` 增加 `InterfaceTheme` 值；Infrastructure 继续使用 schema 1 的 `workspace-layout.json`。缺字段默认浅色，非法枚举按坏配置保留并提示；沿用原子保存与备份，不新增主题文件，不进入会话导出。
- 主题菜单即时应用后尝试保存，失败明确显示未保存并保留磁盘原值。重置窗口布局保留主题；子对话框从 owner 继承当前选择。
- 主题遍历跳过整个 `TerminalView`，包括偏好预览；字体、背景和 ANSI 颜色继续由终端设置与内容控制。共享界面字体不覆盖终端字体。
- 高对比度优先系统颜色，按钮恢复原生绘制；系统颜色变化重新应用。窗口标题栏、滚动条、系统消息框、文件/颜色选择器仍由 Windows 绘制。原生组合框等局部外观服从系统能力，不承诺全窗口像素级深色。
- 继续使用代码绘制的协议/分类图标，按 DPI 缩放；按钮使用直角边框、文字层级和可见焦点。保留删除/覆盖/关闭确认、既有标签鼠标操作和异步清理所有权。

## 验证与边界

检查浅色和深色的对比度、按钮交互状态、弹窗继承、保存失败、重启恢复、重置保留主题、终端配色隔离和窄窗口操作；保留同场景截图。模拟高对比度规则只验证映射与原生绘制分支，真实系统高对比度切换、多 DPI 和混合显示器体验仍需环境验收。
