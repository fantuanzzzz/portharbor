# ADR 0016：终端重连、缓冲查找与标签操作边界

- 日期：2026-10-29
- 状态：已采纳

## 背景

P06 需要让失败终端可显式恢复，减少查找历史输出和关闭多个标签的操作成本，同时不能改变已完成的连接生命周期、取消、主机信任及不重放约定。

## 决策

- 重连只针对当前终端标签：先等待旧 `ITerminalSession.CloseAsync()`，再创建新的 `TerminalConnection`、`TerminalView` 和连接状态控件。旧实例的输入、取消令牌、屏幕缓冲和命令不复用。
- 查找直接消费当前 `TerminalScreen` 的 `History` 与 `Lines`，大小写不敏感并滚动到命中行；不建立索引、不写文件、不跨标签，不把查找当成远端命令。
- 复制反馈通过主窗口状态栏显示；剪贴板失败保持非阻塞。原有选区、全屏缓冲、自动复制和多行粘贴确认不改变。
- 标签上下文操作只影响窗口：重命名不改会话，复制标题不创建会话，关闭其他标签按既有确认逐一等待资源清理。长标题通过 tooltip 保留可识别性。

## 代价与验证

查找仅覆盖内存中当前标签的终端内容，重启后不保留搜索状态；重连会清空当前终端屏幕，用户需重新执行命令。通过终端生命周期、UI 关闭、注入式重连、缓冲查找和标签消息检查验证；真实远端掉线、多 DPI、系统剪贴板和高对比度仍需人工环境验收。详细操作见[终端工作流说明](../TERMINAL-WORKFLOW.md)。
