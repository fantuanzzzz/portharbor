# 0008：本地诊断消息目录与安全呈现

日期：2026-10-27；状态：已实施，当前工作区待提交。

## 背景

连接错误码与阶段已经稳定，但对应中文文案散落在 UI 的 `DiagnosticPresenter` 中。纯 Application 检查无法验证最终提示，新增枚举值也可能静默落入默认文案。下一步先抽离现有本地文案，不扩展语言或采集诊断数据。

## 决策

- Application 内嵌 `Resources/DiagnosticMessages.resx`，集中保存错误码、连接阶段、生命周期回退文字、准备连接/外部 RDP 启动文案，以及错误/操作编号格式。目录使用 `Error_`、`Stage_`、`State_` 前缀与枚举名称对应。
- `DiagnosticMessageCatalog` 用 ResourceManager 读取受信任的内嵌文本。当前只有一套中文默认资源；不同 CurrentUICulture 回退到同一资源，不表示已经支持英文或其他语言。没有引入第三方包、外部配置文件或可执行资源。
- 将无控件依赖的 `DiagnosticPresenter` 移入 Application，继续按现有优先级组合状态、阶段和错误。正常关闭显示“已关闭”，RDP 成功只表示外部客户端已启动，错误提示继续追加 8 位操作编号。UI 控件调用方式不变，准备连接文字也从目录读取。
- 未定义的数值枚举使用稳定回退：未知错误、无阶段后按状态显示、未知状态显示连接异常。已定义枚举缺少资源时不静默伪装为正常提示，由检查阻止遗漏进入发布。
- 呈现只使用枚举与 OperationId，不读取 ConnectionDiagnostic.Message 或原始异常文本。Retryable 不参与文案拼装，也不把主机、路径、密码、私钥或终端控制字符插入消息。

## 验证

共享检查核对资源键与全部枚举完全对应，检查缺失/多余项、所有正常/错误映射及未定义枚举回退。通过 zh-CN、en-US、fr-FR、ar-SA 验证默认资源回退；七种协议遍历所有状态、阶段和错误组合，确认原始消息/Retryable 的变化不会改变安全文案。

Windows UI 检查继续覆盖后台线程更新、失败清理后保留错误，并新增准备连接、未知值回退和操作编号显示。发布冒烟验证消息资源包含在 Application 程序集中。

## 限制与复审

本轮只集中连接诊断文案，不包含平台能力说明、普通菜单/文件操作提示或全应用多语言设置。现有重试、连接分类、日志/终端输出策略不变；不新增诊断日志、遥测或诊断包导出。

引入第二种语言、切换语言设置、用户可编辑文案、更多诊断字段或诊断包时复审。翻译资源需保留格式参数、纯文本及脱敏契约；不得直接把任意异常 Message 作为资源参数。
