# P04 会话库效率与活动记录

日期：2026-10-28。适用于当前 Windows / WinForms 版本。

## 操作路径

侧栏提供「全部 / 收藏 / 最近」切换。每次启动默认显示全部；搜索条件在本次视图切换时保留，收藏或最近无结果时可清空搜索或切回全部。

会话树以固定的 `User sessions` 为显示根节点，现有分类和默认分类放在其下；收藏保留原分类层级，最近按顺序平铺在此根节点下。根节点不写入会话/分类配置、不参与连接或会话编辑；无结果时也保留，供用户定位和新建分类。

| 操作 | 入口及行为 |
| --- | --- |
| 收藏 / 取消收藏 | 选中会话，在「会话」菜单或右键菜单操作；收藏显示 ★ 标记 |
| 最近连接 | 显示最近 20 个已保存会话的连接尝试，重复连接移到最前；悬停可查看尝试时间 |
| 搜索 | 匹配会话名、主机、协议及完整分类路径；全部/收藏保留祖先文件夹，最近按尝试顺序平铺并带分类路径 |
| 清空搜索 | 搜索框旁「清空」或框内 Esc；当前视图不变 |
| 键盘定位 | Ctrl+Shift+F 到搜索；Down / Up 选择第一个 / 最后一个匹配会话并进入树；Enter 在搜索框连接首个匹配，在树内连接已选会话 |
| 键盘切换区域 | 沿用 F6 / Shift+F6；视图操作栏可用 Tab 聚焦、方向键选择和 Enter 激活 |
| 重命名 | 会话菜单或右键菜单；取消保留原值，保存保持 ID、收藏、最近记录和已有密码；需要时先解锁密码库 |
| 新增 / 复制 | 沿用编辑器；保存后切回全部、清空搜索并定位到结果，状态栏显示保存结果；复制使用新 ID，不复制密码、收藏或最近记录 |
| 新建分类 | 会话菜单和树右键菜单统一为「新建分类」；选中 User sessions 或右键空白处时新建顶层分类，选中分类时新建其子分类，选中会话时在其所属分类下新建；完成后切回全部并定位结果 |
| 清空收藏 / 最近 | 会话菜单或右键菜单，确认后分别清空当前集合；不删除会话及密码，也不清另一集合 |
| 删除会话 | 继续确认删除会话及密码，并清理收藏/最近关联 |

最近记录表示用户已经发起尝试，**不表示登录成功**。校验无效、能力不可用或取消密码输入时不记录；未保存的临时会话不加入。一个已保存会话在编辑器中使用本次临时参数连接时，仅关联原 ID，不保存临时参数或凭据。RDP 外部客户端的重新打开按钮沿用原行为；最近时间记录进入连接页/能力恢复后开始尝试的时间，不作为远程登录或每次客户端启动审计日志。

收藏/最近入口按 ID 解析当前会话，再走原连接路径。密码来自现有密码库或本次输入，主机信任仍由原 SSH/SFTP 工厂和配置服务处理。没有自动连接、命令重放或凭据副本。

## 数据与失败处理

安装/便携模式均在当前配置目录保存 `session-activity.json`，schema 1，包含 `Activity.Favorites`（会话 ID）和 `Activity.Recent`（ID 与 `AttemptedAt`）。时间以 UTC 写入，提示使用本地时间；不保存会话名称、主机、协议参数、密码或指纹，不进入会话导出。收藏上限 10000，最近上限 20；未发生变化时不建立空文件。启动冒烟禁用活动读写，避免污染分发包。

保存使用临时文件、刷盘、原子替换并保留上一份 `.bak`；成功后才更新内存中的收藏/最近集合。写入失败显示独立状态栏提示，收藏及清空不显示为成功，最近记录失败不阻止用户连接。缺文件/缺字段使用空集合；坏配置、未知版本或非法 ID/重复值保留原文件，拒绝静默覆盖。需要时通过「设置 → 打开配置目录」检查，并先移走原文件保管再重启恢复。

会话及凭据删除与活动记录属于两个独立文件的操作。先完成会话删除，再清理活动引用；第二步失败时明确提示，不回滚已完成的删除。视图总是过滤不存在的 ID，所以下次查询不会显示已删除会话；正常重启/刷新会重试有效文件中的残留清理。损坏文件不自动覆盖。

清空操作清理当前记录；上一份 `.bak` 和自行复制的历史备份仍可能包含旧 ID 与时间，需按个人需求另行保管或清理。此功能不提供跨进程合并、云同步或跨配置目录自动迁移。

## 验收边界

自动检查覆盖规则、安装/便携存储、备份、坏文件及占用失败、历史有界/去重、删除残留与重试、搜索/空状态、键盘、重启、凭据读取和复制/重命名保护；保留浅色和深色截图。实际多 DPI、真实服务器及设备专项沿用技术方案边界；连接 fixture 不代表远程登录验收。
