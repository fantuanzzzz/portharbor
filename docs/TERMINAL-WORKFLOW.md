# P06 终端工作流

日期：2026-10-29。适用于当前 Windows / WinForms 版本。

## 连接与重连

终端标签在顶部提供「重新连接」，终端右键菜单也提供同一操作。重连先请求旧 `ITerminalSession.CloseAsync()`，等待读写和适配器释放完成，再创建新的连接实例；旧输入队列、取消令牌、终端屏幕和滚动状态都不会复用，也不会自动重放命令。重连失败继续沿用连接状态栏和安全诊断，不改变主机密钥、凭据或最近连接规则。

连接状态仍由 `ConnectionStatusLabel` 呈现连接中、已连接、失败、取消和关闭；错误在后续清理状态到达后保持可见，新的连接开始时才清除旧错误。连接标签中的「重新连接」按钮与终端菜单都在同一 UI 线程入口，后台失败继续由窗口安全观察器处理。

## 查找与复制

终端上下文菜单和 `Ctrl+F` 打开查找提示。查找只读取当前 `TerminalScreen` 的历史与可见行，大小写不敏感；命中后滚动到对应历史行并显示结果，未命中显示稳定提示。空查询不执行操作，不向远端发送输入，也不写入配置、日志或活动记录。查找不提供跨标签、文件或重启后的索引。

复制沿用 `Ctrl+Shift+C`、上下文菜单和选区自动复制偏好；没有选区时复制当前终端缓冲。成功或空结果在主窗口状态栏反馈，剪贴板异常不会阻止终端。多行粘贴确认、bracketed paste、右键粘贴及终端字体/配色的当前标签范围保持不变。

## 标签操作

标签右键菜单提供重命名、复制标题、关闭当前和关闭其他标签。重命名只改变当前窗口标题，不改变会话名称、会话库、凭据或最近记录；长标题显示完整 tooltip。关闭其他标签逐一沿用既有确认和可等待清理，文件传输及终端连接先取消/释放再销毁控件；外部 RDP 窗口不随标签关闭。

双击标题、点击关闭按钮、中键关闭及 `Ctrl+W` 的既有行为保留。关闭确认取消时标签和连接不变，确认后才等待资源清理。P06 没有引入自动重连、命令重放、持久化查找历史或新的终端数据文件。
