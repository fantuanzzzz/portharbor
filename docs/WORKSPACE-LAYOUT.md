# P02 工作台布局与窗口记忆

制定日期：2026-10-28。实现范围为当前 Windows / WinForms 工作台；视觉主题按 P03 单独推进。

## 布局示意与操作路径

```text
文件 / 会话 / 窗口 / 设置 / 帮助
新建连接 | 连接 | 编辑 | 搜索会话 | 会话库
┌─ 会话库（拖动分隔条调宽度）─┬─ 连接标签 ────────────┐
│ 全部 / 收藏 / 最近           │                     │
│ 搜索 / 清空 / 结果提示       │                     │
│ 分类 / 会话树               │ 终端 / 文件 / 开始页 │
│ 操作及快捷键提示            │                     │
└─────────────────────────────┴─────────────────────┘
会话统计 / 配置模式 / 操作提示
```

新建、连接和编辑可从操作栏或会话菜单进入；连接/编辑仅在选择会话时启用。搜索入口显示会话库并聚焦搜索框。现有分类管理、导入导出、密码库和诊断入口保留。

P04 在会话库加入收藏/最近切换、搜索清空和结果提示；全部/收藏沿用分类树，最近按尝试时间平铺。操作和活动保存约定见[会话库说明](SESSION-LIBRARY.md)。

| 操作 | 入口 / 快捷键 |
| --- | --- |
| 新建连接 | 操作栏 / 会话菜单 / Ctrl+N |
| 搜索会话 | 操作栏 / 窗口菜单 / Ctrl+Shift+F |
| 连接已选会话 | 操作栏 / 会话菜单 / 会话树 Enter / 双击 |
| 编辑已选会话 | 操作栏 / 会话菜单 / 会话树 F2 |
| 显示/隐藏会话库 | 操作栏 / 窗口菜单 / Ctrl+Shift+B |
| 切换焦点区域 | F6：搜索框、会话树、工作区；Shift+F6 反向 |
| 关闭标签 | 窗口菜单 / Ctrl+W / 原有鼠标手势 |
| 恢复默认布局 | 窗口菜单 |

操作栏使用原生溢出菜单，窗口较窄时仍可访问；菜单保留完整操作路径。开始页协议按钮随工作区宽度换行，并可滚动。布局恢复将窗口限制在当前屏幕工作区，保留任务栏和标题栏可访问；屏幕断开后回到当前有效屏幕。

## 持久化约定

窗口位置、正常大小、最大化状态、侧栏宽度及显示状态独立保存到配置目录 `workspace-layout.json`，沿用安装/便携路径。位置使用桌面坐标，大小同时记录 DPI，恢复时按当前 DPI 换算并限制到屏幕工作区；最小化不是启动状态，不覆盖最后一次正常位置或最大化选择。

移动、调整大小或侧栏后延迟合并写入，确认退出后再保存一次；取消退出不触发退出专用保存。恢复默认布局立即应用并尝试保存，保留界面主题，不改变会话、密码和终端偏好。不在程序启动冒烟中自动保存布局。P03 在同一 schema 1 文件的 `Layout.Theme` 保存界面选择（0 浅色、1 深色）；缺字段默认为浅色，具体约定见[视觉规范](VISUAL-DESIGN.md)。

保存采用临时文件、刷盘、原子替换及一份 `.bak`，成功后才更新已保存状态。缺文件使用默认；损坏、无效或未知版本保留并提示，拒绝自动覆盖。出现此提示时从「设置 → 打开配置目录」检查，必要时先将原文件移走保管再重试。无法写入不阻止连接或退出，窗口底部显示未保存提示；没有后台云同步或逐会话布局。

## 验收范围

需验证安装/便携存储、正常/最大化/最小化、重启、拖动及隐藏侧栏、窄窗口、屏幕断开、DPI 换算、错误配置和写入失败，以及搜索/树/工作区键盘操作。真实多显示器切换、100%/125%/150%/200% 系统缩放和高对比度须单独注明人工验收状态，不能用计算规则测试替代。
