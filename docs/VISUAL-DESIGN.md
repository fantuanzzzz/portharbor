# P03 视觉规范

日期：2026-10-28。先确定浅色样本，再使用同一组语义值映射深色；当前 WinForms 框架保持不变。

## 样本与层级

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面底色 | `#F4F6FA` | `#151C29` |
| 内容/输入表面 | `#FFFFFF` | `#202A3B` |
| 次级表面/侧栏 | `#EDF1F7` | `#192231` |
| 正文 | `#202C40` | `#E6EDF7` |
| 次要文字 | `#53647A` | `#ADBBD0` |
| 主操作 | `#245FC7` | `#245FC7` |
| 主操作文字 | `#FFFFFF` | `#FFFFFF` |
| 选中/悬停 | `#E2ECFC` | `#304562` |
| 分隔/边框 | `#B9C5D6` | `#65758B` |
| 成功文字 | `#17653E` | `#80DAB0` |
| 警告文字 | `#805600` | `#F0CE79` |
| 错误/危险文字 | `#B32635` | `#FFADB5` |

```text
主操作：  [ 保存并连接 ]  蓝底白字，每个表单只强调主要提交
普通操作：[ 仅保存 ] [ 取消 ]  表面色 + 边框
危险操作：[ 删除 ]  红字 + 明确动作文字，继续保留原有确认
禁用：   [ 连接 ]  独立底色/文字，不可点击
焦点：   [ 搜索会话 ]  清晰边框/焦点虚线，键盘也可发现
状态：   “身份验证失败…” / “已连接”  文字 + 语义色，不只依赖颜色
```

界面正文统一 Microsoft YaHei UI 9pt，系统回退；标题采用同字体加粗。间距采用 4/8/12/16/24 的逻辑尺寸；普通操作至少 32 高、表单操作区留 12 间距。使用清晰的 1px 边框与直角，不引入装饰性阴影或自定义无边框标题栏。系统滚动条、文件选择器、消息框与窗口标题栏沿用 Windows 行为。

图标继续使用代码绘制的分类/终端/文件/桌面体系，统一描边并随主题映射；工具栏动作保留文字，避免仅靠图标猜测。标签选中态、会话树选中态及焦点、文件列表表头/行和按钮默认/悬停/按下/禁用/焦点共同遵循语义配色。

## 设置与范围

「设置 → 界面主题 → 浅色 / 深色」即时应用，保存到已有 `workspace-layout.json` 的 `Layout.Theme` 字段（0 浅色、1 深色），缺字段默认浅色；沿用 schema 1，不增加独立主题文件。主题保存失败应提示，不显示为已保存；不改会话导出内容。恢复默认布局保留已选主题。

覆盖主窗口、开始页、侧栏、菜单/操作栏/状态栏、会话编辑器、文件视图、终端设置、诊断对话框及文本输入提示。系统高对比度优先使用系统颜色和原生按钮绘制，主题选择仍保留，退出高对比度后可恢复；运行期间系统颜色变化重新应用。

界面主题不修改 `TerminalView` 或其预览的字体、背景、ANSI 调色板及用户默认；终端内容仍按 P01 偏好显示。P04 收藏/最近及查找交互见[会话库说明](SESSION-LIBRARY.md)；文件队列、编辑器字段校验和终端查找已分别由 P08、P05、P06 实现，见各功能说明；本页保留 P03 视觉样本基线。
