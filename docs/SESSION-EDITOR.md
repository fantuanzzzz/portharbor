# P05 会话编辑器

日期：2026-10-28。适用于当前 Windows / WinForms 界面。

## 操作与字段

从「新建连接」、开始页协议按钮、会话菜单的「编辑…」或树内 F2 打开编辑器。基础区显示名称、分类路径、协议及当前协议的必要字段，高级设置默认收起，可使用复选框展开；窄窗口内容可滚动，底部操作区固定可达。

| 协议 | 基础字段（不含公共名称/分类/协议） | 高级字段 |
| --- | --- | --- |
| SSH | 主机、端口、用户名、密码/私钥口令、保存密码 | 私钥路径 |
| Telnet | 主机、端口 | 无专用高级字段 |
| RDP | 主机、端口、用户名、密码、保存密码 | 全屏、剪贴板共享 |
| FTP | 主机、端口、用户名、密码、保存密码 | 初始远程目录、显式 TLS |
| SFTP | 主机、端口、用户名、密码/私钥口令、保存密码 | 私钥路径、初始远程目录 |
| Serial | 串口（可手动输入）、波特率 | 数据位、校验、停止位、流控 |
| Shell | 程序 | 参数、可选工作目录 |

切换协议只改变可见字段，不清空草稿；每个已访问协议分别记住本次端口，首次切到另一协议使用其默认端口。此端口草稿仅在当前编辑窗口中保留；保存时仍使用原有单一 `Session.Port`，没有新增逐协议配置文件。Shell 参数保留空格，不作裁剪。

| 按钮 | 结果 |
| --- | --- |
| 仅连接 | 使用本次参数和密码连接，不保存会话参数或密码 |
| 仅保存 | 保存会话；勾选保存密码时沿用主密码流程，不建立连接 |
| 保存并连接 | 先保存成功，再连接；保存失败或取消主密码步骤不继续连接 |
| 取消 / Esc | 丢弃草稿，原会话不变 |

Enter 在普通文本框中执行默认的「保存并连接」；Tab / Shift+Tab 遍历可见字段及操作，折叠的高级字段不进入焦点顺序。协议选择、密码显示及高级展开使用原生组合框/复选框键盘行为。与此前一样，操作提交后保存、主密码或连接阶段的提示在主窗口处理；本轮未把这些后续失败改成编辑器内重试。

## 就地校验与凭据

首次提交检查当前协议字段，所有错误显示在对应输入下方，并定位第一个错误；修改后重新检查，已修正的提示立即清除。名称、主机/端口、RDP 主机附带端口、串口及 Shell 必需程序由 Domain 的 `GetValidationErrors()` 提供字段及消息，`Validate()` 使用同一结果；分类路径继续使用 Application 的 `GroupPath.Validate`。未提交的空白草稿不提前显示错误。数值控件限制合法范围。

此校验不探测服务器是否可达、不校验账户或私钥内容；手动输入程序名仍支持 PATH 查找，工作目录可留空。实际文件访问、私钥格式、连接及登录失败沿用原诊断和主机信任流程。平台能力不可用时两个连接按钮禁用并说明原因，仍可仅保存；提交连接前再检查能力变化。

密码默认隐藏，可明确勾选显示；窗口失去激活或切到不使用密码的协议时恢复隐藏，不修改口令文本。密码/口令不进入字段错误或路径选择器参数。保存密码的提示同时说明主密码和安装模式的 Windows 用户保护；密码保存规则及 RDP 外部客户端限制仍按项目 README。

主窗口编辑带已保存密码的现有会话前，若密码库被锁定先请求解锁；取消或跳过则停止编辑，保留原密码。解锁后读取当前密码再进入草稿，防止无关字段修改把未读取的密码当空值覆盖。用户主动清空密码或取消保存密码仍沿用已有删除凭据语义。复制会话继续使用新 ID、不带原密码；仅连接不会保存新密码，但现有主机信任、最近尝试和诊断记录仍按各自约定处理。

## 路径选择与验证

私钥、Shell 程序可选文件，Shell 工作目录可选文件夹；也可直接手动输入。原生选择器由编辑器作为模态 owner，每次选择后释放；取消保留原值，选择本身不读取私钥、不执行程序、不创建目录。选择器异常显示固定提示并允许手动输入，不显示原异常的私人路径。

文件选择复用 `IFilePicker`；新增仅返回目录路径的 `IFolderPicker`，Windows 适配仍在 `PortHarbor.Platform.Windows.Forms`。两个端口均不包含窗口或句柄，没有新增依赖包、用户数据文件或会话 schema。决定见 [ADR 0015](adr/0015-session-editor.md)。

专项入口（先完成 Release 构建，在可交互 Windows 桌面执行）：

```powershell
dotnet run --project tests/PortHarbor.Checks -c Release --no-build -- --ui-editor artifacts/session-editor --results artifacts/session-editor/editor-ui-results.json
```

规则检查覆盖七协议及字段定位；UI 检查覆盖草稿、三种操作与真实配置差异、取消、密码保护、选择路径、键盘、最小窗口和浅色/深色截图。原生选择器检查拦截显示调用，不代替人工操作系统对话框；实际多 DPI、高对比度、设备和服务器专项仍需相应环境。最终数量与报告见[开发日志](DEVELOPMENT-LOG.md)。
