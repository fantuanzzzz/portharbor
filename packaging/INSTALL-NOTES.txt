--- English ---

This installer includes the .NET 8 Desktop Runtime. No separate .NET installation
or administrator rights are needed. Windows 10 1809 or newer, x64, is required.

Program files: %LOCALAPPDATA%\Programs\PortHarbor (or the folder you select).
Sessions, credentials and preferences: %LOCALAPPDATA%\PortHarbor.
Do not install into a portable copy or the user data directory.

Run this installer again to update the same installation. Close PortHarbor first.
Use Windows Settings > Apps > PortHarbor > Uninstall to remove the program.
Uninstall preserves sessions, credentials, preferences, logs and unrecognized files.
The installer does not import or move existing portable data.
